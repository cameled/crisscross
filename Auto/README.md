## 口径约定

- 金额单位：亿元人民币；销量单位：万辆/辆。
- **Capex** 统一采用现金流量表「购建固定资产、无形资产和其他长期资产支付的现金」。
- **有息融资** 采用：短期借款 + 长期借款 + 一年内到期的长期借款 + 应付债券（含一年内到期）+ 其他流动负债中的债券/超短融。
- **比亚迪中国市场销量** = 全球总销量 − 海外销量（CnEVPost 派生口径，非公司直接披露）。
- 全球新能源采用 BEV + PHEV（IEA/Benchmark 口径）；巴西「电动化」采用 ABVE 广义口径（BEV + PHEV + HEV + HEV Flex）。
- 各国「汽车销量」统计口径不同，只适合看趋势，不适合小数点级横向比较。
