# 全球新能源市场：趋势与月度

对应原稿第 12–13 项。全球新能源 = BEV + PHEV（IEA / Benchmark 口径）。

## 12. 近 5 年全球新能源大趋势

| 年份 | 全球销量约 | 全球新车渗透率 |
| --- | ---: | ---: |
| 2021 | 660 万 | ~9% |
| 2022 | >1,000 万 | ~14% |
| 2023 | 接近 1,400 万 | ~18% |
| 2024 | >1,700 万 | >20% |
| 2025 | >2,000 万（约 2,100 万） | **25%** |

IEA：2025 年全球电动车销售超过 2,000 万辆，同比约 +20%，**全球每 4 辆新车中约 1 辆为 BEV/PHEV**。

### 2025 年关键地区

| 地区 | 新能源占新车 |
| --- | ---: |
| 中国 | ~55% |
| 欧洲整体 | ~28% |
| 美国 | <10% |
| 东南亚 | 接近 20% |

欧盟按 ACEA 注册口径：BEV 188.04 万 + PHEV 101.59 万 = **289.63 万辆**，约占欧盟新车 **26.8%**。

### 比亚迪重要增长市场（2025）

| 市场 | BEV+PHEV 约 | 状态 |
| --- | ---: | --- |
| 巴西 | 18 万辆 | 9% 渗透（+40% 左右，IEA 未明示） |
| 泰国 | 14 万辆 | +70%，近 1/4 市场 |
| 印度 | 16.5 万辆 | +75%，约 4% |
| 东南亚整体 | >50 万辆 | 市场翻倍 |

要点：
> 增长重心从「主要依赖中国」转为「中国成熟 + 欧洲增长 + 拉美/东南亚快速渗透」。

## 13. 最近 12 个月全球新能源月销量

单位：万辆。

| 月份 | 全球新能源销量约 | 核实 |
| --- | ---: | --- |
| 2025-09 | 210 | ✅ Reuters |
| 2025-10 | 190 | ❓ |
| 2025-11 | 200 | ❓ |
| 2025-12 | 210 | ❓ |
| 2026-01 | 120 | ❓ |
| 2026-02 | 110 | ❓ |
| 2026-03 | 175 | ❓ |
| 2026-04 | 160 | ❓ |
| 2026-05 | 180 | ❓ |
| 2026-06 | 200 | ✅ Benchmark |
| 2026-07 | 185 | ✅ Benchmark |
| **2026-08** | **183** | ✅ Benchmark |

已核实锚点：
- 2025-09：全球首次达到约 210 万辆；中国约 130 万、欧洲 42.75 万（+36%）、北美约 21.5 万（+66%）。
- 2026-07：185 万辆，同比 +9%；1–7 月累计 1,150 万辆。
- 2026-08：183 万辆，同比 +2%；1–8 月累计 1,340 万辆，同比 +4%。

2026-08 区域同比（Benchmark 原文）：中国 −11%、欧洲 +36%、北美 −33%。
（中国约 103 万、欧洲约 38 万、北美约 14 万、其他地区约 29 万及「其他地区 +97%」为待核数值。）

结论：

> 全球新能源并未停止增长，而是发生**增长来源迁移**：中国增速下降 + 欧洲增长 + 新兴市场高速增长。这与比亚迪自身「中国销量下降 + 海外销量翻倍」高度重合。
